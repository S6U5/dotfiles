# nix-duplicate-check

## これは何のためのスキルか

`nix/home.nix` の `home.packages` にツールを宣言していても、`$PATH` の並び順次第で
Homebrew版や手動配置版のバイナリが優先され、Nix側が実際には使われていない
(=無駄にディスクを消費しているだけ、かつバージョンがズレて宣言と実態が食い違う)
ことがある。実例として `ripgrep` が Homebrew(15.1.0)と Nix(15.2.0)で二重に入り、
`home.nix` の宣言と違う古いバージョンが実際に動いていたケースがあった。

このスキルは、その種の「Nixで宣言したはずが実は別の場所のバイナリが使われている」
状態を機械的に検出し、削除してよいかどうかを次の基準で分類する。

## 削除してよい/いけないの判定基準

- **削除しない(保持)**: macOS/Linuxディストリビューション**標準搭載**のバイナリと
  重複している場合。Nixを全て消したときにOSの基本機能まで壊れるため。
- **削除候補**: **macOS標準ではなく、ユーザー自身が(Nix導入前も含めて)個別に
  インストールしたもの**と重複している場合(Homebrew経由、apt経由、手動ダウンロード
  配置など)。Nix版が既にあるので実質的な二重管理であり、「Nixを将来やめる日が来たら
  その時に入れ直せばよい」ため今は削除してよい、という考え方。
- **要目視確認**: `home/.local/bin/` 由来の自作コマンドと**たまたま同名**なだけの
  可能性があるもの(別物として扱う)。

## ワークフロー

### 1. 検出スクリプトを実行する

```sh
.claude/skills/nix-duplicate-check/scripts/check-duplicates.sh
```

このスクリプトは `nix/home.nix` の `home.packages` を1件ずつ読み、各コマンドが
実際に `~/.nix-profile/bin/` 側で解決されているか(`command -v` の結果と比較)を
確認する。ズレがあれば、実際に使われているバイナリのパスから出どころを分類する
(`/usr/bin` 等 → OS標準、`/opt/homebrew` 等 → Homebrew、`~/.local/bin` の生バイナリ
→ 手動配置、`~/.local/bin` かつ `home/.local/bin/` へのシンボリックリンク → 自作
コマンドの可能性)。バージョンが取得できる場合は Nix版・実際に使われている版を
両方表示し、不一致があれば警告を添える。読み取り専用で、削除等の変更は一切行わない。

コマンド名がパッケージ名と異なるもの(例: `ripgrep`→`rg`、`neovim`→`nvim`)は
スクリプト冒頭の `cmd_for_pkg` にマッピングを持っている。新しいツールを
`home.nix` に追加してこの対応表に無い場合、結果が「要手動確認」になるので、
その場合はコマンド名を手動で調べて `cmd_for_pkg` に追記する(スキル自体を保守する)。

### 2. 結果をユーザーに提示する

「分類」列ごとに整理して報告する。特に「削除候補」と「バージョン不一致」は
目立たせる(宣言と実態が食い違っている=バグに近い状態のため)。

### 3. 削除は必ず確認を取ってから実行する

「削除候補」と判定されたものについて、実行コマンド(`brew uninstall <pkg>` や
`rm <path>`)を提示し、ユーザーが明示的に承認してから実行する。このスキル自身は
検出のみで、勝手に `brew uninstall` や `rm` を実行しない([破壊的な操作は確認を
取ってから](/CLAUDE.md)という本リポジトリ全体の方針に従う)。

実行後は同じスクリプトを再実行し、対象コマンドが `OK`(Nix版がそのまま使われて
いる)に変わったことと、バージョン不一致が解消したことを確認する。

## 注意点

- Linux/WSL側の「OS標準判定」は `dpkg` の `Essential` フラグを見る簡易的な実装
  (rpm系ディストリビューションは未対応で「不明」判定になる)。判定に自信が
  持てない場合はスクリプトも正直に「不明」「要手動確認」と返すので、その場合は
  ユーザーに直接聞く。
- `home/.local/bin/` に置かれた自作コマンド(CLAUDE.mdの「自作コマンド」の項参照)
  と、たまたま同名になった外部ツールを混同しない。前者は削除対象ではない。
- 機密情報・個人情報を報告や修正に含めない(CLAUDE.md最重要ルール)。
