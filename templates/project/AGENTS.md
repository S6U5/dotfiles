## コマンド

<!-- エージェントはここをそのまま実行する。コピペで動く正確な形で書くこと。
     特に「単一テストの実行方法」は重要(全テストは遅く、修正ループが長くなる) -->

- 依存導入: `npm ci`
- 開発サーバー: `npm run dev`
- テスト(全体): `npm test`
- テスト(単一ファイル): `npm test -- path/to/foo.test.ts`
- lint / 型チェック: `npm run lint && npm run typecheck`
- フォーマット: `npm run format`
- ビルド: `npm run build`

## ディレクトリ構成

<!-- 主要な場所と役割だけ。全ディレクトリを列挙しない -->

- `src/` — アプリ本体(エントリポイント: `src/main.ts`)
- `src/components/` — UI コンポーネント(1ファイル1コンポーネント)
- `tests/` — テスト(`src/` と同じ構造を鏡写しにする)
