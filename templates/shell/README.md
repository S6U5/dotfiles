# シェルのローカル設定(local.sh)の雛形

`~/.config/shell/local.sh`(git 管理外)の書き方見本。`local.sh` はマシン固有・プライベートな設定の置き場で、`init.sh` が共通設定の最後に読み込む。

## 使い方

```sh
cp templates/shell/local.sh.template ~/.config/shell/local.sh
```

コピー先で必要な部分のコメントを外し、実際のサービス名・キー名・パスを記入する。

## なぜ雛形方式か

`local.sh` の中身(どのサービスのラッパーを持っているか、キー名を何にしているか)は、それ自体が利用状況の一覧になるためコミットできない。一方で「wincred で遅延取得する」「取得失敗時は止める」といった**書き方の設計**は残したい。そこで設計だけをプレースホルダ名の雛形としてコミットし、実名はコピー先(git 管理外)にのみ存在させる(`templates/` の方式。AGENTS.md「管理方式の選択」参照)。

雛形へ書き方を還元するときは、実名・実パスが混ざっていないか必ず全文を精査すること。
