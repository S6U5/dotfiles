# テスト実行

テストを実行して結果を報告してください。

## 対象

$ARGUMENTS

（引数がない場合は全テストを実行）

## 手順

1. プロジェクトのテストフレームワークを特定（Jest, pytest, go test など）
2. 指定されたテストを実行
3. 失敗したテストがあれば原因を分析
4. 修正案を提示（自動修正はしない）

## 出力形式

```
## 結果サマリー
✅ パス: X件
❌ 失敗: X件
⏭️ スキップ: X件

## 失敗したテスト
### [テスト名]
- 期待値: ...
- 実際: ...
- 原因: ...
- 修正案: ...
```
