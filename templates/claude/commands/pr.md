# Pull Request 作成

現在の変更から Pull Request を作成してください。

## オプション

$ARGUMENTS

（例: `--draft`, `--base develop`）

## 手順

1. 現在のブランチと変更内容を確認
2. コミット履歴から変更の目的を把握
3. PR タイトルと説明を生成
4. `gh pr create` で PR を作成

## PR テンプレート

```markdown
## 概要
[この PR で何を実現するか 1-2文]

## 変更内容
- [主要な変更点を箇条書き]

## テスト
- [ ] ユニットテスト追加/更新
- [ ] 手動テスト実施
- [ ] CI パス確認

## スクリーンショット
（UI変更がある場合）

## 関連 Issue
Closes #XXX
```

## 注意

- タイトルは50文字以内
- 変更が大きすぎる場合は分割を提案
- WIP の場合は `--draft` を使用
