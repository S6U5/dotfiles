# ドキュメント生成

指定されたコードのドキュメントを生成してください。

## 対象

$ARGUMENTS

## 生成内容

### 関数・メソッドの場合

```
/**
 * [1行の説明]
 *
 * [詳細な説明（必要な場合）]
 *
 * @param {型} 引数名 - 説明
 * @returns {型} 戻り値の説明
 * @throws {エラー型} どんな時にスローするか
 * @example
 * // 使用例
 * const result = functionName(arg);
 */
```

### モジュール・ファイルの場合

```markdown
# モジュール名

## 概要
[このモジュールの役割]

## 主要な関数/クラス
- `functionA`: [説明]
- `ClassB`: [説明]

## 使用例
[コード例]

## 依存関係
- [依存モジュール]
```

## 注意

- 既存のコードスタイルに合わせる
- 自明なことは書かない（`// iをインクリメント` など）
- WHYを重視（WHATはコードを見ればわかる）
