# バグ修正

報告されたバグを調査・修正してください。

## 問題

$ARGUMENTS

## 手順

1. **再現確認**: 問題を再現できるか確認
2. **原因調査**: ログ、スタックトレース、関連コードを調査
3. **根本原因特定**: なぜこのバグが発生したか
4. **修正案作成**: 最小限の変更で修正
5. **副作用確認**: 他の機能への影響がないか
6. **テスト追加**: 回帰テストを追加

## 出力形式

```
## 原因
[なぜバグが発生したか]

## 修正内容
[何をどう変更するか]

## 影響範囲
[この修正で影響を受ける箇所]

## 確認方法
[修正が正しいことの確認手順]
```

## 注意

- 応急処置より根本解決を優先
- 修正前に必ず原因を説明
- テストがないコードには回帰テストを追加
