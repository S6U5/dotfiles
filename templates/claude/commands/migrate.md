# マイグレーション

コードやデータのマイグレーションを計画・実行してください。

## 対象

$ARGUMENTS

（例: `React 17 → 18`, `CommonJS → ESM`, `MySQL → PostgreSQL`）

## 手順

1. **現状分析**: 影響範囲を調査
2. **計画作成**: 段階的な移行計画を立案
3. **互換性確認**: 破壊的変更をリストアップ
4. **テスト準備**: マイグレーション前後の比較方法
5. **実行**: 承認後に段階的に実行
6. **検証**: 動作確認とロールバック手順

## 出力形式

```
## 影響範囲
- ファイル数: X件
- 主な変更箇所: [リスト]

## 破壊的変更
| 変更 | 影響 | 対応 |
|-----|-----|-----|
| ... | ... | ... |

## マイグレーション計画
### Phase 1: [準備]
### Phase 2: [実行]
### Phase 3: [検証]

## ロールバック手順
[問題発生時の戻し方]
```

## 注意

- 一度に全部やらない（段階的に）
- 各段階でテストが通ることを確認
- ロールバック可能な状態を維持
