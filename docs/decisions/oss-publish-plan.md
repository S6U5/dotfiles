## 検討した代替(公開の可否)

- 公開しない(「公開できる規律を保ったプライベートリポジトリ」を完成形として肯定する)
- 今すぐ公開する

## 選んだ理由(公開の可否)

- 公開 dotfiles は「使用ツール目録・環境の輪郭を晒す」という OSINT 材料としての側面があるが、これは dotfiles というジャンル自体が業界標準として既に正規化しているベースライン相当のリスクであり、機密ゼロが達成済みの本リポジトリでは受容できると判断した。
- 判断材料だった「自分の標的価値の変化」を確認したが、以前と同水準で変化はなかった。

## 検討した代替(公開の順序)

- 今すぐ公開する
- TODO を全て片付けてから、Git の全履歴を1コミットに圧縮したうえで公開する(採用)

## 選んだ理由(公開の順序)

- コミットメッセージに Claude Code のセッションリンク(`Claude-Session: https://claude.ai/code/session_...`)が多数残っている。claude.ai の共有設定は既定で Private(セッション所有者以外は閲覧不可)だが、念のため公開前に消しておきたい。全履歴圧縮であれば1回の操作でこの問題も同時に解消できる。
- 履歴圧縮(全コミットハッシュの変更)は不可逆に近い操作のため、実行タイミングは「もう後戻りしない」公開直前の1回に絞る。
- 圧縮時は `origin/claude/initial-structure` / `origin/claude/new-session-dwqjjo`(いずれも旧 main の祖先で用済みの古いリモートブランチ)も削除しないと、そちら経由で旧コミット(圧縮前の履歴)がそのままアクセス可能に残ってしまう点に注意。

## リポジトリ保護・PR 運用の方針

- **main のブランチ保護を導入する**(直push禁止・PR経由必須、CI(`lint`/`install-test (ubuntu-latest)`/`install-test (macos-latest)`/`gitleaks`)を required status check に)。ただし admin(自分)への強制(`enforce_admins`)はしない(緊急時の直push退路を残す)。個人リポジトリでレビュー必須化はしない(自分以外にレビュアーがいない構造上不可能なため)。
- **GitHub の仕様上の制約**: branch protection・repository ruleset のいずれも、プライベートリポジトリの無料プランでは設定できない(`403: Upgrade to GitHub Pro or make this repository public`)。実際の設定は公開切り替えのタイミングで行う。
- **外部からの PR は受け付けない、Issue は受け付ける**。GitHub の repository 設定 `pull_request_creation_policy` を `collaborators_only` にすることで技術的に実現できる(2026-02 追加のGitHub新機能、公式ドキュメントで確認済み)。実際の設定は公開切り替え時に行う。
- **ローカル側の補完策として、pre-commit フック(`.githooks/pre-commit`)で main ブランチへの直接コミットをブロックする**(実装済み、公開状態に関係なく既に有効)。サーバー側のブランチ保護だけだと push した時点で初めて弾かれ手戻りが大きい。特にエージェント(Claude Code等)がブランチルールを見落として main のまま作業してしまう事故を、コミット時点で早期に検知する狙い。`git commit --no-verify` で回避可能なため、ローカルフックのみでは不十分(バイパス可能)であり、公開切り替え後のサーバー側ブランチ保護と併用する。
  - **履歴圧縮(全履歴の1コミット化)への影響は無い**ことを確認済み: `git filter-repo` は内部的に `git commit-tree`(配管コマンド)を使うため pre-commit フックは発火しない。手動で `git checkout --orphan <一時ブランチ>` 方式を使う場合も、コミット時点のブランチ名が `main` ではないため引っかからない(検証済み)。

## トレードオフ

- 公開が「TODO完全消化」に依存するため、公開までのリードタイムが伸びる。
- 履歴圧縮によりコミット単位の変更履歴(意思決定の過程そのもの)は失われる。個々の決定理由は `docs/decisions/` の ADR 群に既に退避してあるため、実害は小さいと判断。
