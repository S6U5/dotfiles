# スリープを止めるコマンド

長い処理を走らせているあいだ PC が眠らないようにする。macOS・WSL・Linux で同じ名前と使い方のコマンド `keepawake`(`home/.local/bin/`)にした。

| 観点 | 電源設定を書き換える(`pmset` / `powercfg /change`) | 常駐アプリ(PowerToys Awake など) | OS にスリープ止めを頼む(採用) |
|---|---|---|---|
| 設定が残らない | ×(戻し忘れると残る。sudo が要るものもある) | ○ | ○(頼んだプロセスが終われば外れる) |
| 追加のインストール | 不要 | 要る | 不要 |
| コマンドの終わりに合わせて外す | ×(自分で戻す) | △ | ○ |
| 蓋を閉じても止める | ○(`pmset disablesleep`) | △ | × |

- macOS: 標準の `caffeinate -i`(`-d` を付けたら `-di`)。コマンドの終了コードもそのまま返る。
- WSL: 眠るのは Windows なので、WSL の中の `systemd-inhibit` は効かない。Windows の `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)` を `powershell.exe` から呼ぶ。スクリプトはクオートの事故を避けて `-EncodedCommand` で渡す(`wincred` と同じ)。`powershell.exe` は標準入力が閉じるまで待ち、標準入力は `keepawake` が握るので、`keepawake` が `kill -9` で終わっても頼みは外れる。`PowerSetRequest` なら `powercfg /requests` に理由を出せるが、呼ぶものが増えるので見送った。
- Linux: `systemd-inhibit --what=sleep`(`-d` で `idle` も)。

## 決めたこと

- 既定では本体だけを止め、画面は消えてよいことにする。処理が終わるのを待つ使い方が主で、画面を点けておく必要は少ないため。画面も止めたいときは `-d` を付ける。
- 止められない環境では、コマンドを渡したときは警告してそのまま実行する。コマンドを走らせることが本来の目的で、何もせずに止まるほうが困るため。渡さないときは非0で終わる。
- `-t` とコマンドは一緒に使えない。どちらで終わるのかが紛らわしいため。
- 名前は `caffeinate` にしない。macOS 標準のコマンドとぶつかるため。

## トレードオフ

- 蓋を閉じたときや、手動のスリープは防げない(macOS は外部ディスプレイが無ければ蓋を閉じると眠る。Windows は「蓋を閉じたときの動作」の設定が優先される)。蓋を閉じても止めたいなら、OS の設定で変える。
- 止めているあいだは低電力の待機に入らないので、電池を使う。必要なあいだだけ掛け、終われば外れる形にしてある。
- WSL では `powershell.exe` の起動と `Add-Type` のコンパイルで、掛かるまでに1〜2秒かかる。
- WSL で立ち上げの途中に `kill -9` で打ち切ると、中身の無い FIFO を入れた一時フォルダが `TMPDIR` に残る(後始末を走らせられないため)。
