# コミットメッセージに接頭辞ルールを導入する

## 検討した代替

- ルールを設けない(現状の慣習: 英語の命令形1行サマリのみ)
- Conventional Commits をフル導入する(接頭辞 + 厳密な構文 + commitlint 等での機械的強制)
- Conventional Commits の接頭辞部分だけを運用ルールとして採用する(採用)

## 選んだ理由

- OSS 公開に伴い、コミットログが「何のための変更か」を一目で分類できる形になっている方が読み手に親切。
- フル導入(commitlint 等のツール導入・CI 強制)は、個人リポジトリの規模に対して過剰。接頭辞の語彙だけ決めて `AGENTS.md` に明文化し、運用で守る軽量な形にした。

## トレードオフ

- 機械的な強制がないため、接頭辞の付け忘れ・表記ゆれが発生しうる(許容)。
