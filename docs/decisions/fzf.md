# fzf をあいまい検索の基盤に採用

## 検討した代替

- fzf を使わず、標準のシェル補完 / `select` だけで済ませる

## 選んだ理由

- fzf を使うと自作コマンド(ディレクトリ移動、git ブランチ切替の `fbr`、zoxide との組み合わせなど)で作れる幅が広がるため採用した。

## トレードオフ

- 依存ツールが無い環境でも壊れないようにする必要がある(CLAUDE.md「外部ツール依存の扱い」)。`command -v fzf` で存在チェックし、無ければ通常の補完や `select` にフォールバックする、または静かにスキップする。
