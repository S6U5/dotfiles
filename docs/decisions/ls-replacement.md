# ls の代替として eza を採用する

## 検討した代替

| 観点 | eza | lsd | 色付き ls のみ(ツール追加なし) |
|---|---|---|---|
| フォルダ/ファイルの見分けやすさ | ○(色+アイコン+`--git` でステータス表示) | ○(色+アイコン) | △(色のみ。アイコンなし) |
| upstream の健全性 | ○(eza-community/eza。非アーカイブ、直近リリース 2026-07、★22.8k) | ○(活発) | ー |
| nixpkgs での状況 | ○(broken フラグなし) | ○ | ー |
| ライセンス | EUPL-1.2(OSI 承認の OSS ライセンス) | Apache-2.0 | ー |

## 選んだ理由

- プロンプト(Starship + Nerd Font)をアイコン主体の見た目に統一済みのため、ls 系もアイコン付きの eza に揃える。exa の後継としてコミュニティ規模が最も大きく、`--git` による git ステータス列など機能面でも十分。
- 2026-08 に package-researcher スキルで確認: upstream は非アーカイブ・活発(最終 push 2026-08-03、v0.23.5)、nixpkgs も broken なし。
- EUPL-1.2 はコピーレフト系だが、dotfiles は eza のコードを取り込まず外部コマンドとして呼び出すだけなので、本リポジトリの MIT 公開方針と問題なく共存できる(「呼び出すのは OK、組み込むのは NG」の方針の範囲内)。

## トレードオフ

- eza が無い環境ではアイコン表示は得られない(`aliases.sh` で色付き ls へフォールバックする。GNU ls は `--color=auto`、BSD/macOS ls は `-G` を実行時判定)。
- アイコン表示は Nerd Font 前提(このリポジトリでは整備済み)。
